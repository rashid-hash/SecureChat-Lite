# SecureChat Lite

A lightweight, production-ready, client-side heavy private temporary chat web app.

## Features
- **Zero Registration**: Anonymous Firebase Auth.
- **Auto-Expiring Data**: Messages vanish exactly 10 minutes after sending.
- **Secure Architecture**: Cryptographically generated URLs. No predictable IDs.
- **Mobile First**: PWA ready, Android optimized, fast CSS animations.

## Setup Instructions (Part 2 Prep)
1. Create a Firebase project.
2. Enable Anonymous Authentication.
3. Enable Firestore Database.
4. Add credentials to `js/firebase-config.js`.
5. Deploy to Vercel/Firebase Hosting.
